# Learnings repo

This is a personal, ongoing study log — not a product or application. Each top-level folder is a distinct technical topic (e.g. `rpc-grpc/`), containing:

- `notes.md` — **the user's own personal notes. Claude must never write to this file.** It's freeform, in the user's own words, and is for them to fill in as they learn.
- `README.md` — topic overview maintained by Claude: goal, plan/curriculum, structure of the folder.
- `log.md` — running progress log maintained by Claude: dated entries of what was set up or completed.
- exercise/tutorial code, usually organized in numbered step folders (e.g. `01-plain-rpc-drb/`)

## Conventions

- New topics get their own top-level folder with a `README.md`, a `log.md`, and an empty `notes.md` for the user.
- Never write to any `notes.md` in this repo — that content belongs to the user only.
- Code in this repo is for learning, not production — favor clarity and comments explaining *why*, over idiomatic terseness.
- When resuming a topic after time away, check its `log.md` and `README.md` for where things left off before writing new code.
