# Learnings repo

This is a personal, ongoing study log — not a product or application. Each top-level folder is a distinct technical topic (e.g. `rpc-grpc/`), containing:

- `notes.md` — freeform notes: what was learned, gotchas, links, open questions
- exercise/tutorial code, usually organized in numbered step folders (e.g. `01-plain-rpc-drb/`)

## Conventions

- New topics get their own top-level folder with at least a `notes.md`.
- Code in this repo is for learning, not production — favor clarity and comments explaining *why*, over idiomatic terseness.
- When resuming a topic after time away, check its `notes.md` first for where things left off before writing new code.
